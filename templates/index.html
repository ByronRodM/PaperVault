Sobre el procesamiento OCR

Al cargar un documento, PaperVault utiliza el motor Tesseract OCR para extraer automáticamente el texto contenido en él. Este texto se almacena en la base de datos y permite buscar el documento por su contenido. El archivo original también se conserva para descarga y visualización.
